> [!quote] Note
> Le joueur se décide à esquiver cette attaque avec ses réflexes primitifs.

![[sortesquive_opportuniste.png|500]]

| DD (1D20)(+VIT) | Effet                                                                                                                                                    |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1               | Le joueur choisi entre encaisser l'attaque **ou** esquiver pour renvoyer l'attaque sur un autre joueur **au hasard**, qui **ne pourra pas se défendre**. |
| 3+              | Esquive l'attaque, qui est renvoyé sur un autre joueur **au hasard**. *Le nouveau joueur ciblé se défend normalement*.                                   |
| 10+             | Esquive l'attaque, qui est renvoyé sur un autre joueur **au choix du défendeur**. *Le nouveau joueur ciblé se défend normalement*.                       |
| 18+             | Esquive complètement l'attaque.                                                                                                                          |
> [!note] Note
> S'il n'y a qu'un seul joueur dans le combat, Le joueur devra toujours subir les dégâts sauf s'il fait 18+
