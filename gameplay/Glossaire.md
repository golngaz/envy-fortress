
| Mot                                                   | Définition                                                                                                                                                                                                                                                       |
| ----------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Altération                                            | Altération ou altérations d'état représente l'état d'un joueur (brûlé, empoisonné etc..). Généralement symbolisé avec des jetons d'altérations d'états correspondants, sur la fiche du personnage.<br><br>Tous les jetons sont considérés comme des altérations. |
| AOE (zone)                                            | *Area Of Effect* — sort ou attaque de **zone**, touchant **plusieurs cibles** à la fois (par opposition à une cible unique). Un sort AOE **ne provoque pas de tour de défense** : les cibles ne résolvent pas leur compétence de défense en réaction ; les éventuels **JdS** du sort, eux, restent dus. Cf. [[Combat]].                                                                                                                          |
| Background                                            | histoire personnelle d'un personnage avant le début de la partie. Le background regroupe ses origines, les événements marquants de sa vie passée et ce qui a forgé sa personnalité.                                                                              |
| Drop                                                  | Loots lâchés par un ennemi                                                                                                                                                                                                                                       |
| Ennemi                                                | Toute entité qui combat les PJ lors d'un combat                                                                                                                                                                                                                  |
| Jeton PA                                              | A ne pas confondre avec les `PA`, ce jeton permet d'avoir 1 `PA` supplémentaire chaque tour par jeton.                                                                                                                                                           |
| Loots                                                 | Équipement, armes etc. récupérable par un joueur ("drop" ennemi ou coffre etc.)                                                                                                                                                                                  |
| MJ                                                    | Maître du jeu. Compte l'histoire et rythme le jeu.                                                                                                                                                                                                               |
| PA                                                    | Point d'actions. Symbolisés par la roue de `PA`. Dépensables afin d'effectuer des sorts ou pour certaines conditions.                                                                                                                                            |
| PNJ                                                   | Personnage non joueur. Englobe les monstres/ennemis, mais aussi les personnages ayant des dialogues incarnés par le MJ                                                                                                                                           |
| Phases de combat                                      | En opposition aux phases de progression, les phases de combats se déroulent en *tour par tour*.                                                                                                                                                                  |
| Phases de progression                                 | Phases dans lesquelles les joueurs avancent dans l'aventure en *temps réel*.                                                                                                                                                                                     |
| PJ                                                    | Personnage joueur (ou "le(s) joueur(s)")                                                                                                                                                                                                                         |
| PV                                                    | Points de Vie. A zéro, le PJ est mort.                                                                                                                                                                                                                           |
| Safe zone                                             | Zone dans laquelle les PJ peuvent se reposer et récupérer leurs `PV`                                                                                                                                                                                             |
| Statistiques de base                                  | Corresponds aux statistiques (`CON`, `CTRL`, `VIT`, `FOR`, `INT`, `VOL`) ajoutés par la classe du personnage.                                                                                                                                                    |
| Statistiques bonus                                    | Corresponds aux statistiques gagnés pour chaque niveau.                                                                                                                                                                                                          |
| Statistiques dérivées                                 | Statistiques calculés à partir des autres statistiques de bases. Précalculées à chaque niveau, elles sont rappelés sur la fiche de personnage. `PV`, `Poid`, `Cases`, `Tours`.                                                                                   |
| Statistiques totales (ou simplement **statistiques**) | Somme des chaque statistique de base et de la statistique bonus.                                                                                                                                                                                                 |
| Temps réel                                            | On parle de temps réel quand le temps se découle normalement. Il est possible d'*accélérer le temps* ou de faire des *ellipses* en *temps réel*.                                                                                                                 |
| Modificateur de (statistique)                         | Modificateur d'une statistique : `(statistique totale / 6) − 1`, arrondi à l'inférieur. Noté `CON+`, `CTRL+`, `VIT+`, `FOR+`, `INT+`, `VOL+`. Exemples : **14** en CON → (14/6)−1 = **+1** ; une stat **sous 6** → **−1** ; **18** → **+2**.                                                                                          |
